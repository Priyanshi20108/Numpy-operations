# NumPy Operations — Quick Reference

A compact, hands-on reference notebook covering the core NumPy operations you reach for most often — array creation, inspecting array properties, reshaping, indexing/slicing, and mathematical & statistical functions. Built as a personal cheat sheet for quick lookup, and useful for anyone getting familiar with NumPy fundamentals.

## 📘 What's Inside

| Section | Covers |
|---|---|
| **Array Creation** | 1D, 2D, and 3D arrays; `np.zeros`, `np.ones`, `np.arange`, `np.linspace` |
| **Array Attributes** | `.shape`, `.ndim`, `.size`, `.dtype` |
| **Reshaping** | `.reshape()`, `.flatten()`, `.ravel()` |
| **Indexing & Slicing** | Basic slicing (1D/2D/3D), boolean indexing/filtering |
| **Mathematical Operations** | `np.add`, `np.subtract`, `np.multiply`, `np.divide`, `np.power`, `np.sqrt` |
| **Statistical Operations** | `np.mean`, `np.median`, `np.sum`, `np.min`, `np.max` |

Each cell includes a short inline comment explaining what the operation does, so it works as a fast lookup reference rather than a full tutorial.

## 🛠️ Tools & Libraries

- Python 3
